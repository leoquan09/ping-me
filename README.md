# ping-me
This is a messaging app that features real time updates using socket.io. It uses a mongoDB database and a node.js backend that saves messages to the database everytime you send a message. This is the first time I've used socket.io and mongoDB and it was really fun. I really reccomend using mongoDB because it requires much less setup to use that other database alternatives like postgres.

You can use it at this link right here: https://socket-messenger-431r.onrender.com/

*please note that the app takes up to a minutes to spin up because it is hosted for free on render.
